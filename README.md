# ecommerce-delivery-analysis-powerbi
Power-BI-Dashboard zur Analyse von 99K Bestellungen eines brasilianischen E-Commerce-Marktplatzes (Olist-Datensatz) — Umsatz, Umsatz nach Kategorie und Lieferleistung über 3 Report-Seiten. Erstellt mit Power Query, DAX-Measures und einem Sternschema-Datenmodell.
